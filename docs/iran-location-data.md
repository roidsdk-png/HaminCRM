# داده استان‌ها و شهرهای ایران

فایل `lib/data/iran-locations.json` شامل ۳۱ استان و ۱۶۵۷ نام شهر یکتا در سطح هر استان است.

- منبع: [sajaddp/list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran)
- نسخه مبنا: تقسیمات کشوری منتشرشده تا سال ۱۴۰۲
- منبع اولیه اعلام‌شده توسط گردآورنده: داده‌های رسمی مرکز آمار ایران و استانداردهای تقسیمات کشوری
- مجوز مجموعه: GNU GPL v3.0

دو ردیف تکراری هم‌نام در یک استان هنگام ساخت فایل برنامه حذف شده‌اند؛ هیچ شهر یکتایی حذف نشده است.
