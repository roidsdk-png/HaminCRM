# Hamin CRM

سامانه یکپارچه مدیریت آمار و داده‌های ربات‌ها، چت‌بات‌ها، آزمون‌های روان‌شناختی و همسان‌گزینی هامین.

## امکانات

- داشبورد کاربران، پیام‌ها، آزمون‌ها و پروفایل‌های همسان‌گزینی
- دریافت امن و idempotent رویدادها از منابع مختلف
- گزارش‌گیری با فیلتر منبع، تاریخ، جنسیت، سن و موقعیت جغرافیایی
- خروجی مدیریتی و بکاپ SQLite
- مدیریت مدیران، نقش‌ها و دسترسی موقت
- رابط فارسی راست‌به‌چپ و واکنش‌گرا
- اتصال‌های آماده برای بله، ایتا، آزمون‌های وب، Matchhamin، Honaz و Redline

## پیش‌نیازها

- Node.js 22.13 یا جدیدتر
- npm
- برای استقرار پیشنهادی: Docker و Docker Compose

## اجرای توسعه

```bash
npm ci
npm run dev
```

در محیط توسعه ورود خودکار مدیر فعال است. داده محلی توسط Wrangler/Miniflare نگهداری می‌شود.

## بررسی کیفیت

```bash
npm run lint
npm run build
npm run test:release
python -m unittest integrations/redline/test_crm_integration.py
```

## استقرار Docker

ابتدا تنظیمات نمونه را کپی و مقادیر امن و تصادفی را جایگزین کنید:

```bash
cp .dev.vars.example .dev.vars
docker compose config -q
docker compose up -d --build crm
curl http://127.0.0.1:3010/api/health
```

فایل `.dev.vars`، دیتابیس‌ها، بکاپ‌ها و کلیدهای منابع عمداً از Git خارج شده‌اند. جزئیات عملیاتی در [docs/deployment.md](docs/deployment.md) آمده است.

## اتصال منابع

منابع رویدادها را به `POST /api/v1/events` می‌فرستند و دو هدر زیر را ارائه می‌کنند:

- `X-CRM-Source`: شناسه منبع
- `X-CRM-Key`: کلید اختصاصی همان منبع

قراردادها و نمونه کلاینت‌ها در [integrations/README.md](integrations/README.md) قرار دارند. اتصال کامل آزمون Redline نیز در `integrations/redline` نگهداری می‌شود.

## امنیت داده

- رمز SSH، توکن پیام‌رسان، کلید API و فایل محیطی نباید commit شوند.
- هر منبع باید کلید مستقل داشته باشد.
- IP خام ذخیره نمی‌شود؛ منابع وب فقط هش یک‌طرفه IP را ارسال می‌کنند.
- پیش از هر انتشار عملیاتی از دیتابیس بکاپ معتبر بگیرید.
