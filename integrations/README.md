# بسته اتصال منابع به CRM

این پوشه فقط کد آماده‌سازی است و هنوز روی هیچ سروری نصب نشده است.

## نگاشت منابع فعلی

- مشاور بله (`/opt/moshaver-eita/bot.php`): نمونه `examples/bale-advisor.php`
- مشاور ایتا و سه آزمون وب: `php/CrmClient.php` از داخل `api.php` سمت سرور
- ربات ازدواج (`/opt/matchhamin-bot/bot.py`): نمونه `examples/matchhamin.py`

روی هر سرور فقط دو متغیر محرمانه تنظیم می‌شود: `CRM_URL` و `CRM_API_KEY`. رمز SSH، توکن پیام‌رسان و کلید هوش مصنوعی به CRM داده نمی‌شوند.

ربات‌های بله و ایتا IP کاربر را دریافت نمی‌کنند؛ شناسه اختصاصی کاربر پیام‌رسان معیار شمارش دقیق است. وب‌اپ می‌تواند IP را فقط در سرور خودش هش کند و `ipHash` بفرستد.

در اتصال نهایی، ارسال رویداد بعد از عملیات اصلی برنامه انجام می‌شود. شکست CRM نباید پاسخ‌دهی ربات، نتیجه آزمون یا امکان تلاش مجدد کاربر را متوقف کند.
